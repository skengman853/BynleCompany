# BynleCompany Docs

Canonical documentation for the BynleCompany repo.

## Sections
- `api.md` API behavior and endpoints.
- `architecture.md` system-level architecture and data flow.
- `data-model.md` storage model and schema notes.
- `product.md` product framing and scope.
- `products/` canonical per-product specs for Assist, Flow, Tasks, and Docs.
- `roadmap.md` product roadmap details.
- `deployment-render.md` deployment runbook for Render.
- `implementation-summary.md` implementation snapshot.
- `company/` internal operations and planning docs.
- `versions/` historical version snapshots.
- `archive/` non-canonical logs and old ad-hoc notes.

## Ownership Rule
- Internal operations, platform runbooks, and product implementation docs belong in this repo.
- Public website messaging, SEO content, and marketing docs belong in `bynle-technologies`.
