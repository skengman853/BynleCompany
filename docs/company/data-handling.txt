1. ROLES
═══════════════════════════════════════════════

Data Controller: The Client (the physio clinic / business)
→ They decide what data is collected and why.

Data Processor: Bynle
→ We process data on behalf of the Client to provide the Service.

═══════════════════════════════════════════════
2. WHAT DATA WE COLLECT
═══════════════════════════════════════════════

From website visitors (via chat widget):
- Name
- Email address
- Phone number
- Chat messages / questions asked
- Timestamp of conversation
- Page URL where chat was initiated

From clients:
- Clinic name, address, contact details
- Logo and branding assets
- FAQ content and service information
- Booking system credentials (if applicable)

4. HOW DATA IS USED
═══════════════════════════════════════════════

Visitor data is used to:
- Respond to visitor questions via the chat widget
- Capture lead information and send to the Client
- Facilitate appointment bookings

We do NOT:
- Sell data to third parties
- Use visitor data for marketing (unless explicitly consented)
- Share data between tenants/clients
- Use client data to train AI models without consent

═══════════════════════════════════════════════
5. DATA RETENTION
═══════════════════════════════════════════════

Active clients:
- Chat logs retained for duration of subscription
- Lead data retained for duration of subscription

After cancellation:
- Data retained for 30 days
- Then permanently deleted
- Client may request immediate deletion

═══════════════════════════════════════════════
7. GDPR RIGHTS
═══════════════════════════════════════════════

Website visitors have the right to:
- Access their data
- Request correction
- Request deletion
- Object to processing
- Data portability

Process: Visitor contacts the Client (Data Controller). Client contacts Bynle if action is needed on our systems. We respond within 72 hours.

═══════════════════════════════════════════════
8. DATA BREACH PROCEDURE
═══════════════════════════════════════════════

If a data breach occurs:
1. Identify and contain the breach immediately
2. Assess what data was affected
3. Notify affected Clients within 24 hours
4. Client notifies the DPC (Data Protection Commission) within 72 hours if required
5. Document the breach and response
6. Implement measures to prevent recurrence
