# Bynle – 12 Month Roadmap

## Vision

Bynle becomes the **AI operating system for service businesses**.

Instead of selling a single chatbot tool, Bynle provides an automation layer that helps businesses:

- handle customer enquiries
- manage bookings
- automate internal workflows
- extract tasks from communication
- collect and manage documents

The long-term product stack will look like:

- Bynle Assist → Customer enquiries & booking automation
- Bynle Flow → Internal workflow automation
- Bynle Tasks → AI task extraction from notes/emails
- Bynle Docs → Document collection & tracking

The goal is to **reduce administrative workload and improve operational efficiency for service businesses.**

Bynle becomes the **AI automation layer for service businesses**.

# Key Founder Principles

1. Start narrow, expand later.
2. Solve real workflow problems.
3. Avoid building features without customer demand.
4. Focus on reliability before expansion.
5. AI should reduce friction, not add complexity.
