# Roadmap

## Phase 1 MVP
- Tenant signup + login
- Settings and FAQs CRUD
- Document upload and indexing
- Chat endpoint with RAG
- Lead capture
- Basic analytics

## Phase 2
- Role-based access control
- Website crawler sources
- Usage-based limits and billing
- SSO or OAuth

## Phase 3
- Advanced routing and human handoff
- Multi-channel (SMS, email)
- Automated review and compliance reports
