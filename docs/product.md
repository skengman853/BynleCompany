# Product spec

## Working name
Bynle platform

## Core goals
- One app, many businesses (multi-tenant)
- Tenant self-service for hours, prices, and availability
- Chatbot answers from tenant settings, FAQs, and documents
- Optional website pages as sources
- Lead capture and analytics
- Guardrailed responses for sensitive topics
- Fast, cheap, observable, and maintainable

## Key components
- Client chat widget
- Tenant admin dashboard
- Backend API with policy and retrieval
- Document ingestion pipeline
- Analytics and lead management

## Success criteria
- Tenant can onboard without support
- Widget installs with a single snippet
- Chat answers cite tenant-owned sources
- Admin can see leads and top questions
