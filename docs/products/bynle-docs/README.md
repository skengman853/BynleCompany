# Bynle Docs v1

This folder is the canonical build pack for the first version of Bynle Docs.

## Documents
- `v1-product-spec.md`
- `v1-api.md`
- `v1-data-model.md`
- `v1-delivery-plan.md`

## Use
- Start with `v1-product-spec.md` for scope and workflows.
- Use `v1-api.md` when building `apps/docs-api/`.
- Use `v1-data-model.md` when extending Prisma and shared types.
- Use `v1-delivery-plan.md` to sequence implementation across `admin-web`, `docs-api`, and `docs-worker`.
